# _MyGame

Toàn bộ code, asset và scene của game nằm trong thư mục này.

Tài liệu của dự án nằm ở thư mục `Docs/` tại gốc project:

- `Docs/README.md`: cấu trúc thư mục, công cụ, cách làm việc
- `Docs/TienDo.md`: mốc, việc tiếp theo, đã làm / chưa làm
- `Docs/FINDINGS.md`: những gì đã tìm ra về game gốc
